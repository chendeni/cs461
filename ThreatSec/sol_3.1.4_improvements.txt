#Propose at least one way of improving the Forrest IDS algorithm. Your proposal should include a sufficiently technical description of the modification, an explanation of how you expect this to improve the IDS, and any potential limitations or shortcomings you could see to your proposed change.
The Forrest IDS can be improved by keeping track of other variables like system call arguments.  Arguments that are boolean values or have a very small range of values should be tracked since it is most likely used for making important decisions such as selecting which mode to use or enabling/disabling a feature of a system call, instead of a piece of data to be processed.  Any rarely used pattern with very few occurrances during normal use should also be considered an anomaly if it is used much more often than normal.
